# stock_m 研究与发现子系统设计规格

日期：2026-08-06

状态：已确认

## 1. 目标

为个人美股投资者提供从策略发现候选股票、调整筛选条件、比较同业、加入自选到进入股票研究页的完整流程。

核心路径：

> 选择策略模板 → 调整条件 → 查看结果 → 快速比较 → 进入股票研究页 → 加入自选分组

首期使用确定性模拟数据或免费/低成本延迟数据。所有数据通过标准化接口访问，后续可以切换到付费实时数据源。

## 2. 范围

### 2.1 包含

- 策略选股器。
- 四套内置筛选模板。
- 自定义条件增删、排序与组合。
- 筛选结果表、分页和排序。
- 市场主题与行业热力图。
- 财报、分红、拆股和公司事件日历。
- 已保存筛选器。
- 自选分组。
- 股票同业比较。
- 从筛选结果进入现有股票研究页。

### 2.2 不包含

- 自定义脚本或编程语言筛选。
- 策略回测和收益排行。
- 自动交易或券商下单。
- 社交分享和公开荐股。
- AI 自动生成买卖建议。

## 3. 产品结构

“发现”一级入口包含四个页签：

| 页签 | 职责 |
| --- | --- |
| 策略选股 | 模板、条件编辑器、结果数量和股票结果表 |
| 市场主题 | 行业、主题、涨跌和估值热力图 |
| 财报日历 | 自选股、模拟持仓和筛选结果中的公司事件 |
| 已保存筛选 | 保存、运行、复制、重命名和删除筛选 |

“自选”一级入口支持多个分组。每只股票显示价格变化、估值状态、下一事件和投资逻辑状态。

股票研究页新增“同业比较”区块，比较成长、盈利能力、估值、动量和风险。系统不生成黑盒综合排名。

## 4. 内置策略模板

### 4.1 高质量成长

- 营收同比增长不低于 20%。
- EPS 同比增长为正。
- 毛利率不低于所属行业中位数。
- 自由现金流为正。

### 4.2 合理估值

- 预期市盈率不高于所属行业中位数的 1.2 倍。
- PEG 不高于 2。
- 自由现金流收益率不低于 2%。
- 净负债与 EBITDA 不高于 3。

### 4.3 财报改善

- 最近季度营收或 EPS 超过一致预期。
- 下一财年 EPS 一致预期在最近 30 天上调。
- 最近季度毛利率同比未恶化。

### 4.4 放量突破

- 当前价格高于 20 日最高价。
- 当日相对成交量不低于 1.5。
- 20 日平均成交额不低于 2,000 万美元。
- 当前价格不低于 5 美元。

模板只是初始条件集合。用户可以修改并另存，不会改变系统模板。

## 5. 筛选条件模型

```ts
type ScreenerOperator = ">" | ">=" | "<" | "<=" | "=" | "between";

interface ScreenerCondition {
  id: string;
  metric: string;
  operator: ScreenerOperator;
  value: number | [number, number];
  period: "CURRENT" | "MRQ" | "TTM" | "FY1";
}

interface SavedScreen {
  id: string;
  name: string;
  conditions: ScreenerCondition[];
  sort: { metric: string; direction: "asc" | "desc" };
  createdAt: string;
  updatedAt: string;
}
```

标准指标名由领域层定义。UI、保存筛选和供应商适配器不得直接使用供应商专有字段。

## 6. 模块边界

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| Screener | 模板、条件校验、筛选执行、排序和分页 | DiscoveryRepository |
| Watchlist | 分组、股票归属和排序 | 本地存储，后续账户 API |
| PeerComparison | 同业选择、指标对齐和比较 | 股票目录、标准化指标 |
| EventCalendar | 财报、分红、拆股和公司事件聚合 | DiscoveryRepository |
| DiscoveryRepository | 面向 UI 的统一读取接口 | 模拟数据或供应商适配器 |

模块之间通过类型化接口通信。任一供应商切换只修改适配器和标准化层。

## 7. 数据流

1. 供应商适配器读取行情、财务、行业和事件数据。
2. 标准化层转换代码、单位、财务周期和指标名称。
3. 缓存记录来源、更新时间和新鲜度。
4. 筛选引擎对标准化股票快照执行条件。
5. 发现页展示结果；用户可以加入自选或进入研究页。
6. 已保存筛选只持久化条件定义，不持久化过期结果。

首期浏览器内筛选模拟数据。后续服务端实现必须保持相同的 `ScreenerCondition` 输入和结果类型。

## 8. 页面行为

### 8.1 策略选股

- 左侧显示策略模板和条件编辑器。
- 主区显示匹配数量、排序控件和结果表。
- 修改条件后立即重新计算结果。
- 结果表默认列为代码、公司、行业、价格、当日涨跌、营收增长、预期市盈率和下一事件。
- 行操作包括“研究”和“加入自选”。

### 8.2 市场主题

- 支持行业和主题两个视图。
- 热力图面积表达市值，颜色表达涨跌或估值偏离。
- 颜色不是唯一信息通道，同时展示数值和方向符号。

### 8.3 财报日历

- 支持周视图和列表视图。
- 优先展示自选股和模拟持仓。
- “预计”与“已确认”日期有明确区分。

### 8.4 自选分组

- 创建、重命名、删除和排序分组。
- 股票可以属于多个分组。
- 删除分组不删除股票研究、投资逻辑或模拟持仓。

### 8.5 同业比较

- 默认选择相同行业且市值接近的最多五家公司。
- 用户可以增删对比公司。
- 所有指标显示单位、周期和来源。
- 数据周期不一致时禁止绘制直接对比图，并解释原因。

## 9. 空白与异常状态

- 指标缺失显示“数据缺失”，不使用零值代替。
- 条件缺少有效数值时阻止执行，并定位到错误条件。
- 条件互相冲突时解释冲突字段。
- 结果为空时提供逐项放宽条件入口。
- 供应商限流时保留最后成功结果，并显示更新时间和过期状态。
- 财报日期未确认时标记“预计”。
- 保存筛选失败时保留未保存草稿并允许重试。
- 删除自选分组采用可恢复软删除。

## 10. 可访问性与响应式

- 表格使用正确的表头、排序状态和行操作标签。
- 条件编辑器可完全使用键盘。
- 焦点样式满足 WCAG 2.2 AA。
- 涨跌和热力图不只依赖红绿颜色。
- 1440 px 显示条件侧栏和结果表。
- 1280 px 压缩非关键列。
- 1024 px 将条件编辑器收进抽屉，并保留核心结果列。

## 11. 测试与验收

### 11.1 单元测试

- 所有运算符。
- `between` 边界。
- 缺失值。
- 多条件交集。
- 模板不可变性。
- 周期与单位标准化。

### 11.2 交互测试

- 选择模板后条件和结果同步更新。
- 修改条件后匹配数量变化。
- 将结果加入指定自选分组。
- 保存、复制、重命名和删除筛选。
- 同业周期不一致时显示阻止原因。

### 11.3 端到端测试

- 高质量成长模板 → 修改条件 → NVDA 结果 → 加入“AI 基础设施”分组 → 打开研究页。
- 财报日历 → 打开自选股事件 → 进入股票研究页。

### 11.4 完成标准

- 四套模板均可执行且结果可解释。
- 用户可以自定义并保存筛选。
- 用户可以创建自选分组并从结果加入股票。
- 用户可以从结果进入研究页并查看同业比较。
- 每个指标和事件都能追溯周期、来源和更新时间。

## 12. 后续子项目

本规格完成后，按顺序分别设计和实施：

1. 持仓与复盘：组合分析、行业暴露、投资日志、提醒和复盘。
2. 数据与账户：真实数据适配器、登录、多设备同步和部署。
