# 交易 Worker 可靠性实施计划

1. 用失败测试定义交易 Job 的 Inbox 去重与失败回滚行为。
2. 为交易处理器注入数据库事务和 `consumeOnce`，保持命令路由不变。
3. 用失败测试定义通用 Worker 生命周期的健康探针与关闭钩子。
4. 扩展 `runWorker`，使旧处理器和新生命周期对象均可工作。
5. 用失败测试定义 Trade Updates 的健康、重连和停止语义。
6. 重构 WebSocket 控制器，显式持有 socket 和重连 timer。
7. 抽取交易后台生命周期，纳入两个对账定时器、活动任务和 WebSocket。
8. 运行定向测试、完整测试与生产构建，审查并合并到 `main`。
